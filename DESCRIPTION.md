This extension provides the functionality needed for integration with ResellerInterface DNS API.
The extension allows you to manage the DNS records of your domains in Plesk.

### Supported record types
- A
- AAAA
- CAA
- CNAME
- HTTPS
- MX
- NS
- SRV
- TLSA
- TXT

### Hints 
- Invalid ttls are set to default values (mostly 86400 seconds)
- Separate zones for subdomains are not supported
